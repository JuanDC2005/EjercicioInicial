Proyecto de introducción al curso 2027

## Todo-List v1.0

Pequeña aplicación para gestionar listas de tareas desde la consola

## Funcionalidades

1. añadir una nueva tarea
2. Borrar una tarea
3. Listar tareas
4. Marcar una tarea como completada
5. Salir del programa

## Implementación

- Se usa la  **última versión de java** JDK27.
- Almacenamiento de tareas en memoria usando `ArrayList<>`
- Gestion del UI con `println` y `Scanner`
